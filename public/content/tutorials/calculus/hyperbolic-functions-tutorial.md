# Hyperbolic Functions Tutorial

This tutorial covers hyperbolic functions, their definitions, identities, derivatives, and integrals.

## Introduction to Hyperbolic Functions

Hyperbolic functions are analogs of trigonometric functions for a hyperbola.

### Definitions

$$\sinh x = \frac{e^x - e^{-x}}{2}$$

$$\cosh x = \frac{e^x + e^{-x}}{2}$$

$$\tanh x = \frac{\sinh x}{\cosh x}$$

$$\coth x = \frac{\cosh x}{\sinh x}$$

$$\sech x = \frac{1}{\cosh x}$$

$$\csch x = \frac{1}{\sinh x}$$

## Identities

$$\cosh^2 x - \sinh^2 x = 1$$

$$\tanh^2 x + \sech^2 x = 1$$

$$\coth^2 x - \csch^2 x = 1$$

## Derivatives

$$\frac{d}{dx} \sinh x = \cosh x$$

$$\frac{d}{dx} \cosh x = \sinh x$$

$$\frac{d}{dx} \tanh x = \sech^2 x$$

$$\frac{d}{dx} \coth x = -\csch^2 x$$

$$\frac{d}{dx} \sech x = -\sech x \tanh x$$

$$\frac{d}{dx} \csch x = -\csch x \coth x$$

## Integrals

$$\int \sinh x \, dx = \cosh x + C$$

$$\int \cosh x \, dx = \sinh x + C$$

$$\int \sech^2 x \, dx = \tanh x + C$$

$$\int \csch^2 x \, dx = -\coth x + C$$

$$\int \sech x \tanh x \, dx = -\sech x + C$$

$$\int \csch x \coth x \, dx = -\csch x + C$$

## Inverse Hyperbolic Functions

$$\sinh^{-1} x = \ln(x + \sqrt{x^2 + 1})$$

$$\cosh^{-1} x = \ln(x + \sqrt{x^2 - 1})$$

$$\tanh^{-1} x = \frac{1}{2} \ln\left(\frac{1+x}{1-x}\right)$$
