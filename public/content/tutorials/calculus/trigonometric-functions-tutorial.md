# Trigonometric Functions Tutorial

This tutorial covers trigonometric functions, their derivatives, and integrals, including inverse trigonometric functions.

## Trigonometric Functions

### Basic Definitions

$$\sin \theta = \frac{opposite}{hypotenuse}$$

$$\cos \theta = \frac{adjacent}{hypotenuse}$$

$$\tan \theta = \frac{opposite}{adjacent}$$

## Derivatives of Trigonometric Functions

$$\frac{d}{dx} \sin x = \cos x$$

$$\frac{d}{dx} \cos x = -\sin x$$

$$\frac{d}{dx} \tan x = \sec^2 x$$

$$\frac{d}{dx} \cot x = -\csc^2 x$$

$$\frac{d}{dx} \sec x = \sec x \tan x$$

$$\frac{d}{dx} \csc x = -\csc x \cot x$$

## Integrals of Trigonometric Functions

$$\int \sin x \, dx = -\cos x + C$$

$$\int \cos x \, dx = \sin x + C$$

$$\int \sec^2 x \, dx = \tan x + C$$

$$\int \csc^2 x \, dx = -\cot x + C$$

$$\int \sec x \tan x \, dx = \sec x + C$$

$$\int \csc x \cot x \, dx = -\csc x + C$$

## Inverse Trigonometric Functions

$$\sin^{-1} x = \arcsin x$$

$$\cos^{-1} x = \arccos x$$

$$\tan^{-1} x = \arctan x$$

## Derivatives of Inverse Trigonometric Functions

$$\frac{d}{dx} \arcsin x = \frac{1}{\sqrt{1 - x^2}}$$

$$\frac{d}{dx} \arccos x = -\frac{1}{\sqrt{1 - x^2}}$$

$$\frac{d}{dx} \arctan x = \frac{1}{1 + x^2}$$

## Integrals Involving Inverse Trigonometric Functions

$$\int \frac{1}{\sqrt{1 - x^2}} \, dx = \arcsin x + C$$

$$\int \frac{1}{1 + x^2} \, dx = \arctan x + C$$

$$\int \frac{1}{\sqrt{x^2 - 1}} \, dx = \ln|x + \sqrt{x^2 - 1}| + C$$ (for |x| > 1)
